# Painel de Ideias

Projeto desenvolvido na disciplina de Programação e Tecnologias para Aplicações Cliente 2.

O Painel de Ideias é uma aplicação feita em React para registrar ideias, marcar quais já foram concluídas e remover as que não forem mais necessárias.

## Funcionalidades

- Adicionar novas ideias
- Impedir o cadastro de ideias vazias
- Mostrar uma mensagem de erro quando o campo estiver vazio
- Listar todas as ideias cadastradas
- Marcar e desmarcar ideias como concluídas
- Riscar visualmente as ideias concluídas
- Remover ideias
- Mostrar a quantidade total de ideias
- Mostrar a quantidade de ideias concluídas

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS
